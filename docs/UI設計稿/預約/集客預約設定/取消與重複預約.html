取消政策

歡迎光臨 Wonder sky。為了保障每一位顧客的權益，如需更改或取消預約，請於預約時間 1 天前 透過本系統完成取消，否則將視為曠職。

重複預約說明

本館目前不提供同個時段的重複預約服務。如您已完成預約，需完成該筆訂單或取消後，方可進行下次預約。

* 以上設定將即時同步至您的會員端介面。
