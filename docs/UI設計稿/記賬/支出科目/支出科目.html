支出科目說明

設定支出科目可以幫助您在進行「關帳」作業時，更精確地追蹤營運成本。 月結項 會出現在月度報表中，用於長期損益分析； 日結項 則會出現在每日交班與金流對帳單中，確保每日現金流準確。

快速設定建議

  • 水電瓦斯費用建議設為月結
  • 零用金支出建議同時設為日/月結
  • 維修費用建議新增分類記錄
