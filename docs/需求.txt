美業 APP 美容師端需求分析文件 (完整整合版)
1. 系統概述
本 APP 專為美業從業人員（美容、美髮、美體、紋繡師等）設計，旨在簡化預約流程、優化客戶經營、即時追蹤業績並提升作品行銷效率。

2. 核心功能模組
2.1 登錄與帳戶安全 (Auth & Account)
多重登錄方式： 支援手機號碼 + OTP 快速登錄、客戶代碼 + 帳號密碼登錄。

權限體系： 分為「店長/管理員」與「美容師」權限。店長可查看全店數據，美容師僅查看個人業績與排班。

個人檔案： 個人頭像、簡介、專長標籤、QR Code 個人名片。

2.2 智能場務表 (Smart Schedule) — 核心模組
視覺化日曆：

月/週/日視圖： 標記門店公休、個人請假、已預約時段。

狀態標籤： 使用不同顏色區分預約狀態（待確認、已鎖定、已完成、已取消、逾時未到）。

行程管理：

新增預約： 選擇會員、服務項目（多選）、加價項目、預計時長、備註。

排班設定： 支持動態調整每日上下班時間、臨時不接單時段、休息時間（Break time）設置。

請假系統： 支持事假、病假申請，自動同步至預約系統避免撞單。

衝突警告： 系統自動比對美容師現有行程與店內設備空置情況，若時間重疊或設備衝突須彈出強提醒。

2.3 會員 CRM 管理 (Member Management)
多層級搜索： 可透過手機號、姓名、生日或會員等級進行模糊搜索。

會員 360 視圖：

基本資料： 含生日提示（當月/當日）、VIP 等級、膚質或偏好紀錄。

消費歷史： 過去的服務項目、購買的產品、評價內容。

資產管理： 剩餘儲值金、課程券/優惠券紀錄、剩餘積分。

溝通互動： 一鍵撥打電話、傳送簡訊、內置 IM 在線溝通（支持發送預約卡片與快捷回覆模板）。

2.4 收入與業績分析 (Performance & Finance)
實時業績看板： * 個人總業績： 區分服務業績（勞務）與商品業績（銷售）。

佣金明細： 每一筆訂單的抽成詳情。

薪資預估： 根據業績自動計算當月預估薪資（扣除個人勞健保或耗材費後）。

排行榜： 店內服務排行、熱銷項目分析。

2.5 作品集與行銷 (Portfolio & Social)
作品管理： 支持上傳高清圖片（多圖）、影片、添加服務項目標籤（如：法式美甲、貓眼）。

內容編輯： 為作品添加文字描述、耗時、使用的產品。

社群互動： 查看客戶評價、回覆評論、分享作品至社交媒體。

2.6 庫存與耗材管理 (Inventory)
領料系統： 美容師領取門店產品（如精油、色膠）的申請與核銷。

進銷存功能： 針對可零售產品的掃碼入庫、出庫、盤點、低庫存預警。

篩選： 按品牌、類別、所屬門店過濾。

3. 非功能性需求
3.1 顯示偏好設定
自定義界面： 美容師可自行決定場務表是否顯示「VIP 提示」、「項目備註」、「客戶全名」。

通知設定： 開啟/關閉預約成功提醒、取消提醒、系統公告。

3.2 系統架構與安全
前後端分離： 採用 React Native (前端) + Midway.js (後端)。

併發處理： 使用 Redis 分散式鎖，確保在搶手時段或熱門活動中，不會出現「一格多約」的情況。

數據安全： 敏感數據加密存儲，支持數據定期備份至 MySQL。

4. 用戶操作流程 (User Journey)
首頁： 美容師登錄後看見當日行程摘要與業績概況。

預約處理： 收到客戶端預約通知 -> 進入場務表確認時間 -> 點擊確認 -> 系統自動發送確認訊息給客戶。

服務完成： 在場務表點擊「完成服務」 -> 系統自動跳轉至結算頁面 -> 關聯會員帳戶扣點或收款。

業績更新： 服務結算後，個人收入模組即時更新數據。

5. 擴展功能建議 (Future Scope)
AI 智能分析： 根據客戶歷史紀錄，自動推薦適合客戶的下一個服務項目給美容師參考。

跨店支援： 針對連鎖品牌，支持美容師在不同分店間的排班切換。
